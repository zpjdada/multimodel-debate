# 可选补充材料

这个目录留给席位自己拿不到的东西：付费会议论文集、中文文献、内部笔记、日志、代码快照、你已经跑过的实验记录。**留空是正常用法**——每个席位都会自己检索，`materials/` 只是补充，不是启动讨论的前提。

放进来之后，在 `research_brief.md` 的"可选二：本地材料"那一节列一张表，写清每份文件的作者/来源、你读到哪一层（完整正文 / 部分 / 仅摘要），以及你希望它支撑什么。席位会认真读你给的每一份，无关文件放进来只会稀释注意力。

几点实际情况：

- 席位读的是文本。扫描版 PDF 没有文字层时读出来是空的，最好同时放一份 `.txt`。
- 知网（CNKI）导出的 `.caj` 席位读不了，请先转成 PDF 或纯文本。知网本身也读不到：检索页停在安全验证，正文要求登录与机构订阅，工具侧没有通道。
- 带公式的材料，纯文本里的公式容易失真；能提供 TeX 或含公式的 HTML 更好。
- 不要放 API key、账号凭据、未脱敏的客户数据或与研究无关的个人资料。

这个目录已 gitignore，不会随包发布。
